# Security policy

Only the latest tagged release is maintained. This utility modifies a local
executable and is intended for reviewed, compatible builds only.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/theoryeast/codex-windows-capture-repair/security/advisories/new).
If private reporting is unavailable, open an issue requesting a private reporting
channel without disclosing exploit details or sensitive information.

Useful reports identify the affected release, a sanitized reproduction and the
potential impact. Do not attach proprietary helpers, full logs, credentials,
private screenshots or local backups.

The project does not disable signature enforcement, change trust stores, alter
app approvals, bypass execution policy, or hide active screen-capture indicators.
Do not use security exclusions to make a blocked candidate run. Prefer an official
signed fix or your organization's approved review/signing process.
