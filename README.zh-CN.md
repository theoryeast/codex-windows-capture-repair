# Windows Computer Use 截图修复工具

[English](README.md) · [MIT 许可证](LICENSE)

用于特定的 Windows Computer Use 截图超时问题：能枚举窗口，但截图出现
`FrameArrived timed out`，点击随后出现缺少坐标几何信息的错误。

这是非官方、本地可回退的兼容修复。修改后的组件没有原始数字签名。
工具不更改系统安全设置、证书信任、应用授权或截图提示设置。

## 使用

下载仓库 ZIP 并解压，先阅读源码。正常使用只需 Windows x64 和系统自带的
Windows PowerShell 5.1，不需要 Python、编译器或联网。

1. 双击 `Check.cmd` 检查当前组件。
2. 截图确实失败且组件兼容时，双击 `Repair.cmd` 修复。
3. 在 Codex 内验证“新截图 → 安全点击 → 再截图确认变化”。
4. 黄框残留时运行 `Stop-Capture.cmd`，需要恢复原版时运行 `Restore.cmd`。

运行前结束其他正在操作电脑的 Computer Use 任务。若组织策略限制下载脚本或
未签名程序，请采用组织认可的审查与签名流程，工具不提供策略绕过。

原始备份保存在 `%LOCALAPPDATA%\CodexCaptureRepair\backups`。
使用过其他本地补丁时，先用原工具恢复原版，再运行本工具。

## 原理

受影响的截图回调在返回前等待图像转换，转换又需要截图调用栈占有的资源，
因而发生阻塞。补丁让外层回调先返回，由独立 MTA 工作线程执行原处理代码。
委托引用保持到工作线程完成，避免线程交接期间提前释放。

黄框是 Windows 的活动截图提示。清理命令通过结束遗留截图会话移除残留，
不会关闭正常截图时的系统提示。

## 更新后的兼容性

当前只支持经过审阅的 Sky 0.7.17 x64 内部布局。每次检查全部原始 PE 节和
关键头部字段。仅签名或时间戳变化、内部代码与数据完全一致的版本可以通过。
新版本内部结构变化时，工具停止并保留原文件，不能保证任意未来版本都可直接修复。

仓库仅发布脚本、源码、测试和软件指纹，不附带 OpenAI 原始或已修改的程序，
也不附带本机备份、日志或截图。详细测试范围见 [验证记录](docs/validation.md)。
